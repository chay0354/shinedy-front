# Shinedy Frontend

React + Vite Hebrew RTL customer app.

## Env

See `.env.example`:

- `VITE_API_URL` — backend API base (e.g. `https://your-api.vercel.app/api`)
- `VITE_ENABLE_STAFF=false` — hides admin/warehouse from customers

## Commands

```bash
npm install
npm run dev
npm run build
```

Deploy to Vercel: build command `npm run build`, output `dist`.
